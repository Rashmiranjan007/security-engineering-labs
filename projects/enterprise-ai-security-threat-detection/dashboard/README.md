# Local dashboard

This is a dependency-free, browser-based dashboard for the synthetic detection report generated by `detector.py`.

## Start it

From this project directory:

```bash
python detector.py
python -m http.server 8000
```

Open [http://localhost:8000/dashboard/](http://localhost:8000/dashboard/) in your browser.

## Dashboard features

- Event, incident, critical-alert, and aggregate-risk KPIs
- Severity distribution and workload exposure summaries
- Search across rule, event type, workload, resource, actor, and event ID
- Severity and environment filters
- Selectable incident rows with investigation details and response recommendations

The dashboard reads `reports/latest.json` generated locally by the detector. It uses no external JavaScript libraries, telemetry endpoint, or third-party service. The sample data is synthetic. Do not put production events, secrets, or personal data into this public repository.

If the report is missing, run `python detector.py` before opening the dashboard. A static file preview opened directly from disk may block JSON loading; use the local HTTP server command above.
